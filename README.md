# Site para gerenciar cartões de vacinas
Para visitar o site, [clique aqui](https://dandastico.github.io/padroesWeb_sitesSVU/index.html)

SVU é um trabalho para a aula Padrões Web, matéria do primeiro semestre da Faculdade SENAC-DF.

Um dos requisitos para a construção do site foi a proibição de utiliização de bibliotecas e frameworks, o site precisava ser construído unicamente com HTML, CSS e JS.

## Objetivo do projeto

SVU significa Sistema de Vacinação Unificada. A ideia principal do projeto foi criar uma solução para todos os hospitais do Brasil, tanto os públicos quanto os privados, conseguirem atualizar de maneira intuitiva e ágil seu cartão de vacinação.

Com o SVU, você também poderia ter acesso à cartão de vacinação de seus dependentes, facilitando os cuidados de quem você ama.

## Meu papel no projeto

O site foi construído em grupo de 6 pessoas, fui o responsável pelas páginas:
- Home
- Pré-agendamento
- Cartões de Vacinas
- Roteiro das Vacinas

Também desenvolvi o logotipo, a identidade visual do site e construí o a barra de navegação.
